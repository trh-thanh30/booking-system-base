# Danh mục file F1-009 và chuẩn hóa frontend

Danh mục gồm thay đổi session/login F1-009 và lượt chuẩn hóa useToast/folder theo yêu cầu. Các dòng **Di chuyển** là file cũ được đưa vào folder vai trò, không phải implementation mới. Import/export của consumer được cập nhật để không giữ bản sao tại đường dẫn cũ.

## Quy ước mới

- `*.view.tsx` ở cấp feature; `index.ts` chỉ re-export.
- File hỗ trợ nằm trong `constants/`, `types/`, `utils/`, `columns/`, `data/` kể cả chỉ có một file. Áp dụng cả section con.
- Component frontend gọi `const { toast } = useToast()`; shared hook và Toaster primitive là nơi phụ thuộc Sonner.
- 23 file hỗ trợ được chuyển folder (gồm auth.utils.ts mới từ F1-009). 12 component chuyển từ Sonner trực tiếp sang useToast.
